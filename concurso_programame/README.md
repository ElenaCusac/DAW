#  _ProgramaMe: Concurso de Programación para Ciclos Formativos_

Este repositorio recopila mis soluciones en Java a distintos problemas del concurso de programación **_ProgramaMe_**, organizadas por volúmenes para facilitar su consulta.

Los enunciados de los ejercicios no se incluyen en este repositorio, ya que pueden consultarse en la plataforma [¡Acepta el reto!](https://aceptaelreto.com/problems/volumes.php), donde se publican los problemas utilizados en el concurso.

## Información relevante
Los ejercicios están organizados siguiendo la estructura de volúmenes utilizada por **_ProgramaMe_**. Sin embargo, los problemas pertenecientes a un mismo volumen no guardan necesariamente relación entre sí; simplemente fueron incorporados al concurso en un periodo de tiempo cercano, por lo que comparten una numeración similar.

## Objetivos
* Practicar algoritmia y estructuras de datos.
* Mejorar la capacidad de resolución de problemas.
* Mantener un registro organizado de las soluciones desarrolladas.
* Servir como material de consulta para futuras revisiones.

## Ejecución del proyecto

Este proyecto utiliza Maven para la gestión de dependencias y compilación.

Para compilar el proyecto:

```bash
mvn clean install
```
