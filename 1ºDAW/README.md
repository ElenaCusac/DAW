# 1º DAW

En este directorio se recopilan los proyectos, ejercicios y prácticas desarrollados durante el primer curso del **Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW)**.

El objetivo de este repositorio es organizar el material realizado a lo largo del curso, documentar el proceso de aprendizaje y servir como referencia para futuros proyectos.

## 📂 Estructura del directorio

```text
1ºDAW
├── Entornos de Desarrollo
└── Programación
```

## 📚 Asignaturas

### 💻 Programación

Ejercicios y proyectos desarrollados en Java para aprender los fundamentos de la programación, la programación orientada a objetos y el desarrollo de aplicaciones de escritorio.

**Contenidos principales:**

- Sintaxis de Java
- Estructuras de control
- Programación Orientada a Objetos (POO)
- Colecciones y estructuras de almacenamiento
- Entrada y salida de datos
- Ficheros
- Interfaces gráficas (Swing)
- Proyecto final con JPA

---

### 🛠️ Entornos de Desarrollo

Prácticas relacionadas con el uso de herramientas de desarrollo y buenas prácticas de programación.

**Contenidos principales:**

- Diseño y realización de pruebas
- Optimización del código
- Refactorización
- Documentación
- Control de versiones con Git
- Calidad del software

---

## 🛠️ Tecnologías utilizadas

- Java
- Maven
- JDK
- NetBeans
- Git
- GitHub
- JPA
- Swing

## 🎯 Objetivo

Este directorio reúne el trabajo realizado durante el primer curso de DAW con el propósito de:

- Consolidar los conocimientos adquiridos.
- Mantener un historial organizado de prácticas y proyectos.
- Facilitar la consulta y reutilización del código.
- Mostrar la evolución del aprendizaje en Java y herramientas de desarrollo.
