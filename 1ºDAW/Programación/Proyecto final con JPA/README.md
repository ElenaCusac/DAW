# Proyecto Final de Programación: Aplicación de Gestión para un Parque de Atracciones

## Descripción

Este proyecto final consiste en una aplicación de escritorio desarrollada en **Java** bajo una arquitectura de persistencia de datos utilizando **JPA (Java Persistence API)** y **Maven**. El sistema interactúa directamente con una base de datos relacional en **MySQL**, cuya estructura (`EstructuraParqueAtracciones.sql`) y datos iniciales (`ScriptInsertarDatos.sql`) se encuentran completamente integrados en el directorio del proyecto. 

Para interactuar de forma intuitiva con la base de datos de atracciones y empleados, la aplicación implementa una **Interfaz Gráfica de Usuario (GUI)** interactiva diseñada en **NetBeans**, lo que permite realizar de manera visual operaciones de consulta, inserción y gestión de la información, respetando las pautas analizadas en el documento de `Restricciones de Diseño.pdf` y siguiendo el modelo del `Diagrama E_R.jpeg`.
