# Programación 

## Descripción

Esta carpeta contiene los ejercicios, prácticas y proyectos realizados durante el módulo de **Programación** del primer curso del **Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW)**.

Durante el módulo se trabajan los fundamentos de la programación utilizando **Java** como lenguaje principal, aprendiendo desde los conceptos básicos hasta técnicas más avanzadas como la programación orientada a objetos, estructuras de datos, gestión de ficheros e interfaces gráficas.

## Contenidos aprendidos

A lo largo del módulo se han trabajado los siguientes conceptos:

- Fundamentos del lenguaje Java.
- Algoritmos y resolución de problemas.
- Programación estructurada.
- Programación Orientada a Objetos.
- Gestión de colecciones y estructuras de datos.
- Tratamiento de errores mediante excepciones.
- Manipulación de ficheros.
- Desarrollo de interfaces gráficas.
- Persistencia de datos utilizando JPA.


## Objetivo

El objetivo de este módulo ha sido adquirir una base sólida en programación, aplicando buenas prácticas de desarrollo y aprendiendo a crear aplicaciones estructuradas, mantenibles y orientadas a objetos.
