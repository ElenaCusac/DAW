# Entornos de Desarrollo

En este directorio se recopilan las prácticas, ejercicios y documentación realizados durante la asignatura **Entornos de Desarrollo** del primer curso del **Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW)**.

La asignatura está orientada a adquirir buenas prácticas de desarrollo de software, aprender a utilizar herramientas profesionales y mejorar la calidad del código mediante técnicas de documentación, pruebas y optimización.

---

## Estructura del directorio

```text
Entornos de Desarrollo/

```

---

## Contenido

### Unidad 3. Diseño y Realización de Pruebas

En esta unidad se trabajan los conceptos relacionados con la verificación y validación del software para garantizar su correcto funcionamiento.

**Temas principales:**

- Tipos de pruebas
- Casos de prueba
- Planificación de pruebas
- Verificación y validación
- Calidad del software
- Detección y corrección de errores

---

### Unidad 4. Optimización y documentación

Esta unidad se centra en mejorar la calidad del código mediante técnicas de optimización, refactorización y documentación.

**Temas principales:**

- Refactorización de código
- Code Smells
- Principios DRY y WET
- Optimización del rendimiento
- Documentación técnica
- Javadoc
- Buenas prácticas de programación

---

## Tecnologías utilizadas

- Java
- NetBeans
- Git
- GitHub
- Javadoc


## Objetivos de la asignatura

Durante el desarrollo de esta asignatura se persiguen los siguientes objetivos:

- Aplicar buenas prácticas de desarrollo.
- Mejorar la calidad y mantenibilidad del código.
- Aprender técnicas de documentación profesional.
- Diseñar y ejecutar pruebas de software.
- Utilizar herramientas de control de versiones.
- Comprender la importancia del trabajo colaborativo en el desarrollo de aplicaciones.


## Organización

Cada unidad contiene los ejercicios y prácticas realizados durante las clases, organizados de forma independiente para facilitar su consulta y mantenimiento.
